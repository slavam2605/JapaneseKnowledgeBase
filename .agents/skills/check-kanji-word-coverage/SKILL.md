# Покрытие «чтение кандзи → слова»

Проверять только новые или изменённые карточки чтения, ожидающие ревью. Доказывать покрытие
записью и чтением; локальные эмбеддинги использовать только для компактной очереди спорных пар,
которую затем смотрит LLM или человек.

## Порядок работы

1. Не читать `knowledge/conventions.md`: процесс ничего не записывает в Anki. Не менять теги,
   поля, колоды или состояние карточек.
2. Перейти в `japaneseCards`, освежить точные колоды и их векторы. Экспорт использует
   AnkiConnect только для чтения; локальная `data/anki_index.sqlite3` обновится.

   ```bash
   cd japaneseCards
   export HF_HUB_OFFLINE=1
   .venv/bin/python tools/export_anki_notes.py --deck '新日本語::Слова'
   .venv/bin/python tools/export_anki_notes.py --deck '新日本語::Чтение кандзи'
   .venv/bin/python tools/build_embeddings.py --deck '新日本語::Слова'
   .venv/bin/python tools/build_embeddings.py --deck '新日本語::Чтение кандзи'
   ```

3. Запустить сканер без аргументов:

   ```bash
   .venv/bin/python tools/check_kanji_word_coverage.py
   ```

   По умолчанию сканер выбирает точный тег `to_review` или иерархический
   `ai_generated::to_review`. Не передавать `--all-kanji`, если пользователь явно не просит
   проверить историю целиком.
4. Открыть `data/kanji_word_coverage_review.md` и сообщить сводку:

   - `COVERED_EXACT` и `COVERED_IN_PHRASE` уже подтверждены поверхностной формой;
   - смотреть только `REVIEW_SEMANTIC`: эмбеддинг — кандидат, не доказательство;
   - раздел `Только в колоде чтения кандзи` — итоговый список непокрытых карточек;
   - полный структурированный результат лежит в `data/kanji_word_coverage.json`.

## Обработка исключений

- Если AnkiConnect недоступен, остановиться и попросить открыть Anki с дополнением AnkiConnect.
- Если отчёт содержит ноль карточек с `to_review`, сообщить это как корректный пустой результат.
  Не подменять его полным сканом.
- Если локальных эмбеддингов не хватает, завершить инкрементальную сборку из шага 2 и повторить
  сканирование.

Сгенерированные JSON/Markdown-отчёты и SQLite-индекс — локальные производные файлы; их не
коммитить и не трактовать как изменение карточек Anki.
